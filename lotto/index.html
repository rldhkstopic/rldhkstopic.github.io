추천 파이프라인

  1. 통계 산출 — 번호별 전체 출현·최근 100회 출현·마지막 출현 후 경과 회차, 합계 분포 백분위.
  2. 전략별 가중치 — 균형: 전 번호 동일. 핫: (최근 출현/기대)². 콜드: 경과 회차에 비례. 혼합: 핫 50% + 콜드 30% + 전체 빈도 20%.
  3. 가중 무작위 추출 — 비복원 추출로 6개. 시드는 회차번호+전략이라 같은 주엔 누가 눌러도 같은 번호.
  4. 역대 분포 필터 — 아래 규칙을 모두 통과할 때까지 재추출.
  5. 게임 간 분산 — 한 세트 안에서 게임끼리 겹치는 번호 2개 이하.

    왜 '공유 회피' 규칙이 있나

    사람이 고르는 번호는 생일(1–31)에 쏠리고, 대각선·등차수열 같은 패턴도 많이 고르고, 예전 1등 번호를 그대로 사는 사람도 있어요. 그래서 31 초과 번호를 최소 1개 포함하고, 등차수열과 과거 1등 조합은 제외해요. 당첨 확률은 그대로지만 당첨됐을 때 여러 명과 나눌 확률은 줄어들어요. 데이터로 정당화할 수 있는 건 이 부분뿐이에요.

    어떤 6개 조합이든 1등 확률은 1/8,145,060으로 똑같아요. 추첨은 독립시행이라 핫·콜드 가중치에 예측력은 없고, 백테스트가 그걸 그대로 보여줘요. 이 앱은 '근거 있는 선택 + 재미'까지예요. 구매는 여유 자금 안에서.
